Replay: ส่งรอบที่จบแล้วออกไลฟ์อีกครั้ง (YouTube / Facebook / RTMP)

เซิร์ฟเวอร์ส่งเอง ไม่ต้องเปิด OBS · ไม่เข้ารหัสใหม่ ภาพเท่าต้นฉบับ · ใช้เน็ตขาออกของเซิร์ฟเวอร์เท่าบิตเรตเวที · ตั้ง In/Out ไว้ = ส่งเฉพาะช่วงนั้น (ตั้งแค่ In = ถึงท้ายรอบ, ตั้งแค่ Out = ตั้งแต่ต้นรอบ; เริ่ม/จบที่รอยต่อท่อน คลาดไม่เกินท่อนละ 2–4 วิ) ไม่ตั้ง = ทั้งรอบ · รอบที่จบแล้วจะถูกลบตามเวลา "เก็บหลังจบไลฟ์" แต่ replay ที่กำลังส่งอยู่ส่งต่อได้จนกดหยุด

Restream: ส่งเวทีสดออกหลายช่องพร้อมกัน (YouTube / Facebook / TikTok)

เวที
ช่องปลายทางสถานะ

Stream key ถูกเก็บไว้บนเซิร์ฟเวอร์เพื่อให้ต่อกลับเองได้ และจะไม่ถูกแสดงกลับมาอีก (เห็นแค่ 4 ตัวท้ายไว้แยกช่อง) · ถ้าเปลี่ยน Server ต้องใส่ key ใหม่ด้วย

"ส่งถึงปลายทางแล้ว" แปลว่าเซิร์ฟเวอร์ของแพลตฟอร์มรับสัญญาณแล้ว ระบบนี้มองไม่เห็นว่าคนดูเห็นหรือยัง ต้องเปิดดูที่แพลตฟอร์มทุกครั้ง · ถ้าเครื่องส่งของเวทีหลุด ทุกช่องจะรอและส่งต่อเองเมื่อภาพกลับมาภายใน 10 นาที เกินนั้นระบบหยุดและปลดช่องให้เอง · จบรายการ: กดจบไลฟ์ที่แพลตฟอร์มก่อน แล้วกด "หยุดทุกช่อง" ที่นี่ · เซิร์ฟเวอร์ส่งภาพเดียวกับที่เวทีส่งเข้ามา ไม่แปลงขนาดหรือแนวภาพ
